### ঘণ্টা (〜じ)

সংখ্যার পরে `じ` বসিয়ে ঘণ্টা বলা হয়। প্রশ্নে `なんじ` (কয়টা)।

| বাংলা | জাপানিজ      |
| ----- | ------------ |
| ১ টা  | いちじ       |
| ২ টা  | にじ         |
| ৩ টা  | さんじ       |
| ৪ টা  | **よじ**     |
| ৫ টা  | ごじ         |
| ৬ টা  | ろくじ       |
| ৭ টা  | **しちじ**   |
| ৮ টা  | はちじ       |
| ৯ টা  | **くじ**     |
| ১০ টা | じゅうじ     |
| ১১ টা | じゅういちじ |
| ১২ টা | じゅうにじ   |

> [!WARN]
> ৪টা = `よじ`, ৭টা = `しちじ`, ৯টা = `くじ` — এই তিনটি নিয়মের বাইরে।

### মিনিট (〜ふん / 〜ぷん)

`ふん` বসে ২, ৫, ৭, ৯-এর সাথে; বাকিগুলোতে `ぷん` (এবং কিছু ক্ষেত্রে ছোট っ)। প্রশ্নে `なんぷん`।

| বাংলা    | জাপানিজ    |
| -------- | ---------- |
| ১ মিনিট  | いっぷん   |
| ২ মিনিট  | にふん     |
| ৩ মিনিট  | さんぷん   |
| ৪ মিনিট  | よんぷん   |
| ৫ মিনিট  | ごふん     |
| ৬ মিনিট  | ろっぷん   |
| ৭ মিনিট  | ななふん   |
| ৮ মিনিট  | はっぷん   |
| ৯ মিনিট  | きゅうふん |
| ১০ মিনিট | じゅっぷん |

### অন্যান্য

- **半 (はん)** = আধা, অর্থাৎ ৩০ মিনিট — `にじ はん` = ২টা ৩০
- **午前 (ごぜん)** = সকাল, **午後 (ごご)** = বিকাল
