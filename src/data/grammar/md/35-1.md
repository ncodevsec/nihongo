Conditional (ば) Form গঠন:

| ধরন | নিয়ম | উদাহরণ |
|---|---|---|
| Group I | い-কলাম → **え-কলাম** + ば | のみます → のめば |
| Group II | ます বাদ + **れば** | たべます → たべれば |
| Group III | — | します → すれば、きます → くれば |
| ない-Form | ない → **なければ** | きなければ |
| い-Adj | い → **ければ** | たかい → たかければ |
| な-Adj / Noun | **なら** | きれい[な] → きれいなら、あめ → あめなら |
