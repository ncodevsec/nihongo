# Grammar descriptions (Markdown)

One file per rule, named after the rule id: `4-1.md`, `26-3.md`, …
The file is the rule's **Description**. Its title, structure and examples live in
`../n5.js` / `../n4.js`. A new rule needs an entry there plus (optionally) a file here.

Supported Markdown
- `### Heading` (section), `#### Small heading`
- `**bold**`, `*italic*`, `` `Japanese / particle` `` (highlighted)
- `- bullets`, `1. numbered`, indented items for sub-points
- Tables (`| a | b |` + `|---|---|`)
- `---` divider
- Callouts: `> [!NOTE]`, `> [!TIP]`, `> [!WARN]` followed by `> text`
